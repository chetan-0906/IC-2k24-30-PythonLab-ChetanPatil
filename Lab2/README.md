# Python Pattern Programs

## 1. Right Angle Triangle Pattern

### AIM

To write a Python program to print a **Right Angle Triangle Pattern** using nested loops.

### LOGIC

1. Take the number of rows as input from the user.
2. Use an outer loop to control the rows.
3. Use an inner loop to print `*` according to the current row number.
4. The number of stars increases by one in each row.
5. Continue until the required number of rows is printed.

### INPUT

The program takes the **number of rows** as input.

**Example:**

```text
Enter number of rows: 5
```

## 2. Pyramid Triangle Pattern

### AIM

To write a Python program to print a **Pyramid Triangle Pattern** using nested loops.

### LOGIC

1. Take the number of rows as input from the user.
2. Use an outer loop to control the rows.
3. Use one inner loop to print spaces before the stars.
4. Use another inner loop to print stars.
5. The number of spaces decreases as the row number increases.
6. The number of stars increases in an odd sequence: `1, 3, 5, 7...`.
7. Continue until the complete pyramid is printed.

### INPUT

The program takes the **number of rows** as input.

**Example:**

```text
Enter number of rows: 5
```

## 3. Inverted Triangle Pattern

### AIM

To write a Python program to print an **Inverted Triangle Pattern** using nested loops.

### LOGIC

1. Take the number of rows as input from the user.
2. Use an outer loop to control the rows.
3. Use an inner loop to print stars.
4. Start with the maximum number of stars in the first row.
5. Decrease the number of stars by one after each row.
6. Continue until only one star remains.

### INPUT

The program takes the **number of rows** as input.

**Example:**

```text
Enter number of rows: 5
```

## 4. Square Pattern

### AIM

To write a Python program to print a **Square Pattern** using nested loops.

### LOGIC

1. Take the size of the square as input from the user.
2. Use an outer loop to control the rows.
3. Use an inner loop to print the same number of stars in every row.
4. The number of rows and columns remains equal.
5. Continue until the complete square is printed.

### INPUT

The program takes the **size of the square** as input.

**Example:**

```text
Enter size: 5
```

## 5. Rhombus Pattern

### AIM

To write a Python program to print a **Rhombus Pattern** using nested loops.

### LOGIC

1. Take the number of rows as input from the user.
2. Use an outer loop to control the rows.
3. Use one inner loop to print spaces before the stars.
4. Use another inner loop to print the required number of stars.
5. The number of spaces decreases in each row.
6. The number of stars remains the same in every row.
7. This creates a slanted square-like shape called a rhombus.

### INPUT

The program takes the **number of rows** as input.

**Example:**

```text
Enter number of rows: 5
```
